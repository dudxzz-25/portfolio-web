## 💻 Executar localmente

Clone o projeto:

```bash
git clone https://github.com/dudxzz-25/portfolio-web.git
```

Entre na pasta:

```bash
cd portfolio-web
```

Inicie um servidor local:

```bash
python -m http.server 8000
```

Acesse no navegador:

```text
http://localhost:8000
```
